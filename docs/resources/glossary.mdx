| Term | Meaning |
|---|---|
| **AUSD** | Agora's US dollar stablecoin, Matocard's only onchain currency. 6 decimals |
| **Available credit** | Limit minus what you owe |
| **Card hold** | The wait before a card top-up counts toward the limit |
| **Cash-out** | Turning AUSD into rupiah in an Indonesian bank account |
| **Collateral** | What you deposited, held as yield-vault shares. Secures your limit |
| **Collateral ratio** | Collateral needed per unit of credit: 150% at score 0, 80% at score 100 |
| **Cycle** | From the first draw to repaying to zero. Qualifying cycles raise the score |
| **Default** | A cycle unpaid after due date plus grace. Collateral worth the debt is seized |
| **Draw** | Borrowing against your limit, to any address |
| **Drip** | The one-time MON a verified account receives for network fees |
| **ERC-3009** | A token standard for transfers signed offchain and submitted by anyone; how sends are gasless |
| **ERC-4626** | The tokenized vault standard, used for the collateral vault and the lender pool |
| **Identity hash** | A keyed hash of a document's country, type and number; the only identity data onchain |
| **Indexer** | Envio HyperIndex, turning contract events into history and records |
| **Limit** | Collateral value ÷ collateral ratio |
| **MON** | Monad's gas token |
| **Passkey** | A login key kept by your phone and unlocked with fingerprint or Face ID |
| **Pending shares** | Collateral still in the card hold |
| **Quote** | An exchange rate locked for 60 seconds |
| **Relayer** | Matocard's service key that submits backend transactions and pays gas |
| **Score** | 0 to 100: Record + Consistency + Volume |
| **Settle** | Repaying everything you owe |
| **Treasury** | Matocard's account that holds the AUSD backing fiat flows |
| **Yield fee** | 20% of collateral yield, kept for lenders |
